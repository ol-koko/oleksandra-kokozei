# Translations review

Every user-facing string in English, Ukrainian and German, grouped by page and case. English (`messages/en.json`) is the source of truth; `messages/uk.json` and `messages/de.json` mirror its keys.

**How to review:** read the uk and de columns side by side with en. Copy is written, not translated word for word: same tone and similar length, formal address («ви», „Sie“), feminine forms for the author (UI/UX-дизайнерка, UI/UX-Designerin). Suggest fixes against the key name.

**Typography:** Ukrainian uses the apostrophe ʼ, quotes «…» and the em dash —. German uses quotes „…“ and the spaced en dash –. A non-breaking space (`&nbsp;` in the tables) keeps a dash from starting a new line.

**Line breaks:** `<br>` in a cell is a line break in the message (`\n`), which the page renders as a new line or paragraph. `{name}` and `<time></time>` are placeholders filled in by the code and must stay as they are.
